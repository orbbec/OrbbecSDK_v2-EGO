## 功能需求

### FR-1 录制文件命名可控
#### FR-1.1 需求描述
Android 端可在开始录制前设置命名参数，设备按规则生成录制文件名。

#### FR-1.2 字段约束
- 为保证字符编码统一，推荐只用 a-z A-Z 0-9 . _ -
- 禁用特殊字符：/ \0 \ : * ? " < > | 空格 $ & ; ! # ~ ` ' * ? [ ] ( ) { } 换行 制表符 回车 及其他控制字符，- 开头 . 开头 .. 结尾也需避免

#### FR-1.3 生效时机
- 仅对“后续开始的录制任务”生效。
- 录制进行中修改命名规则，不影响当前正在写入的文件。
- 同一目录下重名时，设备自动去重，例如：10001_task_0001_1。


### FR-2 TF 卡文件/目录删除
#### FR-2.1 需求描述
Android 端可先查询设备 TF 卡中指定目录下的所有文件，再从中选择指定文件/目录执行删除。

#### FR-2.2 查询目录文件（删除前前置接口）
##### FR-2.2.1 查询对象
- 输入为设备 TF 卡可识别的绝对目录路径。
- 返回该目录下的所有文件和目录项（不递归）。

##### FR-2.2.2 查询前校验
- 路径必须为 UTF-8、非空、长度受限。
- 禁止 `..`、绝对路径越界、非法分隔符、控制字符。
- 目标目录不存在时，返回 `DIR_NOT_FOUND`。
- 目标路径不是目录时，返回 `INVALID_ARGUMENT`。
- 无权限访问时，返回 `PERMISSION_DENIED`。

##### FR-2.2.3 返回字段
每个文件项至少包含：
- `name`：文件名（不含路径）。
- `path`：文件绝对路径。
- `size`：文件大小（字节）。
- `lastModified`：最后修改时间（时间戳或 ISO 8601 字符串）。
- `isWriting`：是否正在写入（用于提示删除风险）。
- `mimeType`：文件类型。

##### FR-2.2.4 查询执行约束
- 目录为空时，返回空列表，不视为错误。
- 查询过程中若某个文件状态读取失败，应跳过该文件并记录警告，不应导致整个查询失败。
- 查询操作应为只读，不得修改、移动或删除任何文件。
- 正在写入的文件也应出现在列表中，但需标记 `isWriting = true`。

#### FR-2.3 删除对象
- 输入为设备 TF 卡可识别的绝对存储路径。
- 支持删除单个文件或者目录。
- 删除对象应来源于 FR-2.2 查询返回的文件列表，Android 端基于返回的 `path` 字段发起删除。

#### FR-2.4 删除前校验
- 路径必须为 UTF-8、非空、长度受限。
- 禁止 `..`、绝对路径越界、非法分隔符、控制字符。
- 目标文件不存在时，返回 `ITEM_NOT_FOUND`。
- 若目标文件在 FR-2.2 查询结果中标记为 `isWriting = true`，应拒绝删除并返回文件占用错误。

#### FR-2.5 删除执行约束
- 目标文件正在写入时，删除应失败并返回文件占用错误。
- 删除成功后，应保证文件不可再次被查询到（即再次调用 FR-2.2 时不再返回该文件）。
- 删除失败时，不应影响其他文件完整性。

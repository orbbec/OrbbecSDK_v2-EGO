CHAPTER 20

SD 卡文件服务

通过 SDK 管理 Ego 设备 SD 卡上的文件：查询、列目录、下载到本机、推送到云端、删除。

20.1 功能概述与适用场景

SD 卡文件服务让上位机可以通过 SDK 直接访问 Ego 设备 SD 卡，支持以下操作：

  • 查询 — 判断某路径是否存在，获取文件大小和类型
  • 列目录 — 获取目录内容（可递归）
  • 下载到本机 — SD 卡 → SDK → 本机磁盘；自动断点续传；大文件（≥ 50 MB）自动 8 路并行加速
  • 推送到云存储 URL — SD 卡 → 固件 HTTP Client → 腾讯云 COS / 阿里云 OSS 等
  • 删除 — 删除文件或目录（目录递归删除）

连接方式
WiFi 网络（必须）

≥ 1.1.8

#include <libobsensor/ObSensor.hpp>
using namespace ob;

ob::Context ctx;
auto rawDevice = ctx.createNetDevice("10.9.191.33", 8090);   // 网络连接，端口 8090
auto device    = DataAcquisitionDevice::fromDevice(rawDevice); // 转为 Ego 扩展类型

20.2 查询文件或目录信息：getSdcardFileInfo

在下载前确认路径是否存在，或获取文件大小：

try {
    ob_device_sdcard_file_info info = device->getSdcardFileInfo(
        "EGO_001_20260920_161901");   // SD 卡相对路径

    if (!info.exists) {
        std::cout << "路径不存在" << std::endl;
    } else if (info.isDir) {
        std::cout << "这是一个目录" << std::endl;
    } else {
        std::cout << "文件大小: " << info.size << " 字节" << std::endl;
    }
} catch (const ob::Error &e) {
    // 仅网络通信失败或路径格式非法（如含 ".."）时抛出
    std::cerr << "查询失败: " << e.what() << std::endl;
}
ℹ 路径不存在不抛异常
路径不存在时 info.exists = false，不会抛出异常。只有通信失败或路径格式非法时才抛出 ob::Error。

ob_device_sdcard_file_info 字段

字段类型说明
existsbool路径是否存在
isDirbool是否为目录（exists=true 时有效）
sizeuint64_t文件字节数（仅文件；目录为 0）

20.3 列出目录内容：getSdcardFileList

// 列出 SD 卡根目录（非递归）
auto entries = device->getSdcardFileList("", false);

for (const auto &e : entries) {
    printf("  %s  %-48s", e.isDir ? "[DIR] " : "[FILE]", e.name);
    if (!e.isDir) printf("  %llu B", (unsigned long long)e.size);
    printf("\n");
}

// 递归列出某个录制目录的全部文件
auto allFiles = device->getSdcardFileList("EGO_001_20260920_161901", true);
参数说明
pathSD 卡路径；传 "" 表示根目录
recursivefalse = 仅当前层；true = 递归子目录；固件最多返回 5000 条

ob_device_sdcard_file_entry 每条记录字段

字段类型说明
namechar[512]文件/目录名；递归模式下含相对路径
isDirbool是否为目录
sizeuint64_t文件字节数（目录为 0）

20.4 下载文件到本机：TO_LOCAL 模式

20.4.1 进度回调定义

进度回调是一个 C 函数指针（不能使用带捕获的 lambda）。建议定义为静态函数：

static void onDownloadProgress(ob_sdcard_download_state state,
                               const char *fileName,
                               int          percent,
                               const char  *md5_base64,  // 仅 DONE 时非空
                               void        *userData) {
    switch (state) {
    case OB_SDCARD_DOWNLOAD_TRANSFERRING:
        if (percent >= 0)
            printf("\r  [%s] %3d%%  ", fileName, percent);
        else
            printf("\r  [%s] 传输中...  ", fileName);
        fflush(stdout);
        break;
    case OB_SDCARD_DOWNLOAD_DONE:
        printf("\r  [%s] 完成", fileName);
        if (md5_base64 && *md5_base64)
            printf("  MD5=%s", md5_base64);   // 可用于完整性校验
        printf("          \n");
        break;
    case OB_SDCARD_DOWNLOAD_CANCELLED:
        printf("\r  [%s] 已取消\n", fileName);          break;
    case OB_SDCARD_DOWNLOAD_FAILED_NOT_FOUND:
        printf("\r  [%s] 失败：路径不存在\n", fileName); break;
    case OB_SDCARD_DOWNLOAD_FAILED_TIMEOUT:
        printf("\r  [%s] 失败：超时\n", fileName);      break;
    case OB_SDCARD_DOWNLOAD_FAILED_NETWORK:
        printf("\r  [%s] 失败：网络错误\n", fileName);  break;
    default:
        printf("\r  [%s] 失败（state=%d）\n", fileName, (int)state);
        break;
    }
}

20.4.2 同步 / 异步下载

// ── 同步（阻塞直到完成）──────────────────────────────────
try {
    device->downloadSdcardFile(
        "EGO_001_20260920_161901/part0001.mcap",  // 设备端 SD 卡路径
        OB_SDCARD_DOWNLOAD_TO_LOCAL,              // 下载到本机
        "part0001.mcap",                          // 本地保存路径
        onDownloadProgress,                       // 进度回调（传 nullptr 表示不需要）
        nullptr,                                  // userData（原样透传给回调）
        false                                     // async=false → 阻塞等待完成
    );
    std::cout << "下载完成" << std::endl;
} catch (const ob::Error &e) {
    std::cerr << "下载失败: " << e.what() << std::endl;
}

// ── 异步（立即返回）──────────────────────────────────────
device->downloadSdcardFile(
    "EGO_001_20260920_161901/part0001.mcap",
    OB_SDCARD_DOWNLOAD_TO_LOCAL,
    "part0001.mcap",
    onDownloadProgress, nullptr,
    true   // async=true → 立即返回，结果通过回调通知
);
// 主线程继续执行，调用 cancelSdcardFileOperation() 可随时取消

20.4.3 断点续传

本地已有部分文件时，SDK 自动从断点继续，无需任何额外参数：

// 首次下载中途中断后，再次用相同本地路径调用即自动续传
device->downloadSdcardFile(
    "EGO_001_20260920_161901/part0001.mcap",
    OB_SDCARD_DOWNLOAD_TO_LOCAL,
    "part0001.mcap",   // 本地已有同名文件 → SDK 自动从文件末尾继续
    onDownloadProgress, nullptr, false
);

20.4.4 下载整个目录

SDK 单次只支持单文件下载；下载整个目录时先枚举、再逐文件下载：

const std::string dirPath   = "EGO_001_20260920_161901";
const std::string localBase = "./recordings/" + dirPath;

// 1. 递归枚举目录内所有文件
auto entries = device->getSdcardFileList(dirPath, true);

int done = 0;
for (const auto &e : entries) {
    if (e.isDir) continue;   // 跳过目录项，只处理文件

    const std::string localPath = localBase + "/" + e.name;

    // 2. 创建本地父目录（伪代码，需按平台实现）
    // createDirs(parentDir(localPath));

    printf("[%d/%zu] %s\n", ++done, entries.size(), e.name);
    try {
        // 3. 逐文件同步下载
        device->downloadSdcardFile(
            e.name,                       // 设备端文件路径（来自枚举结果）
            OB_SDCARD_DOWNLOAD_TO_LOCAL,
            localPath,
            onDownloadProgress, nullptr, false
        );
    } catch (const ob::Error &err) {
        fprintf(stderr, "  跳过 %s: %s\n", e.name, err.what());
    }
}
⚡ 大文件自动加速
文件 ≥ 50 MB 时，SDK 自动启用 8 路并行分块下载（HTTP Range 请求），明显提升 WiFi 吞吐效率，无需任何额外配置。

20.5 推送文件到云存储 URL：TO_URL 模式

这种模式下，设备固件直接向指定 URL 发起 HTTP PUT 请求，把 SD 卡文件上传到云端。上位机（SDK）负责生成预签名 URL，不参与实际数据传输。

⚠ 网络要求
设备所在 WiFi 网络必须能访问公网。固件仅支持 http://，不支持 https://。 
// 1. 在上位机生成预签名 PUT URL（以腾讯云 COS 为例）
const std::string cosUrl = generateCosPresignedUrl(
    secretId, secretKey, bucket, "EGO_001_20260920_161901/calibration.yaml");
// URL 格式: http://bucket.cos.region.myqcloud.com/path?q-sign-algorithm=sha1&...

// 2. 让设备推送文件到该 URL（同步等待设备回报完成）
try {
    device->downloadSdcardFile(
        "EGO_001_20260920_161901/calibration.yaml",  // 设备端路径
        OB_SDCARD_DOWNLOAD_TO_URL,                   // 推送到 URL
        cosUrl,                                       // 预签名 PUT URL
        onDownloadProgress, nullptr,
        false   // 同步等待固件完成
    );
} catch (const ob::Error &e) {
    std::cerr << "推送失败: " << e.what() << std::endl;
}

批量异步推送整个目录

auto entries = device->getSdcardFileList("EGO_001_20260920_161901", true);

for (const auto &e : entries) {
    if (e.isDir) continue;

    // 每个文件单独生成预签名 URL（上位机负责，设备无需知道密钥）
    const std::string url = generateCosPresignedUrl(secretId, secretKey, bucket, e.name);

    // async=true → 全部异步启动，SDK 自动限流到最多 2 个并发
    device->downloadSdcardFile(
        e.name, OB_SDCARD_DOWNLOAD_TO_URL, url,
        onDownloadProgress, nullptr, true
    );
}
// SDK 内置信号量，超出 2 个并发的请求自动排队，调用方无需额外限流
ℹ 并发限制说明
固件最多同时处理 2 个上传任务。SDK 内置信号量，第 3 个及以上请求自动在 SDK 侧排队等待槽位释放，业务层无需额外控制。

20.6 进度回调状态一览

回调函数签名：

void callback(ob_sdcard_download_state state,   // 当前状态（下表）
              const char *file_name,             // 当前文件名
              int         percent,               // 进度 0~100；-1 表示未知
              const char *md5_base64,            // 文件 MD5（Base64）；仅 DONE 时有值
              void       *user_data);            // 调用方透传的指针
值枚举名状态含义
0 TRANSFERRING 传输中 percent = 0~99 实时进度；-1 表示大小未知（续传 / 目录）
1 DONE 成功 percent=100，md5_base64 含文件 MD5（Base64），可验证完整性
2 FAILED 失败 未分类失败
3 CANCELLED 取消 调用 cancelSdcardFileOperation() 后取消
4 FAILED_NOT_FOUND 失败 设备端路径不存在（HTTP 404）
5 FAILED_TIMEOUT 超时 网络超时或传输长时间停滞；重新调用会从断点续传
6 FAILED_NETWORK 失败 网络错误（DNS 失败、TCP 断线等）
7 FAILED_SERVER 失败 远端服务器拒绝（HTTP 5xx 或上传目标返回非 2xx）
8 FAILED_BUSY 繁忙 固件上传槽位已满，稍后重试
9 FAILED_CAMERA_STREAMING 冲突 设备正在视频流传输，文件服务被拦截；停止视频流后重试

MD5 完整性校验示例

case OB_SDCARD_DOWNLOAD_DONE:
    if (md5_base64 && *md5_base64) {
        printf("[%s] 完成  MD5=%s\n", file_name, md5_base64);
        // 与预期 MD5 对比，验证文件完整性
        if (std::string(md5_base64) == expectedMd5) {
            printf("  校验通过\n");
        } else {
            printf("  ⚠ MD5 不匹配，文件可能损坏\n");
        }
    }
    break;

20.7 取消正在进行的操作：cancelSdcardFileOperation

// 可从任意线程安全调用，立即通知所有进行中的操作停止
device->cancelSdcardFileOperation();
// 被取消的任务将通过回调收到 OB_SDCARD_DOWNLOAD_CANCELLED
特性说明
线程安全可在回调线程、UI 线程或任意后台线程调用
noexcept不抛异常，可安全用于析构函数或紧急停止路径
无副作用未运行任何操作时调用，静默忽略
同步调用阻塞中的 async=false 调用会抛出 ob::Error（"operation cancelled"）

20.8 删除文件或目录：deleteSdcardFile

try {
    // 删除单个文件
    device->deleteSdcardFile("EGO_001_20260920_161901/part0001.mcap");

    // 删除整个目录（固件递归删除，操作不可撤销）
    device->deleteSdcardFile("EGO_001_20260920_161901");

    std::cout << "删除成功" << std::endl;
} catch (const ob::Error &e) {
    std::cerr << "删除失败: " << e.what() << std::endl;
}
⚠ 不可撤销
目录删除由固件递归处理，操作完成后无法恢复。请在 UI 层完成二次确认后再调用。

20.10 注意事项与最佳实践

下载到本机（TO_LOCAL）

  • 文件 ≥ 50 MB 时 SDK 自动使用 8 路并行下载，充分利用 WiFi 带宽，无需额外配置。
  • 下载中断（超时、网络错误）后，重新调用相同本地路径会自动续传，无需手动处理。
  • 并行下载失败后，SDK 自动清除本地预分配文件，下次重新全量下载，不会留下损坏文件。

推送到 URL（TO_URL）

  • 预签名 URL 有效期建议 ≥ 预计上传时长（大文件按设备出口带宽估算）。
  • 每个文件单独生成预签名 URL，不要多个文件共用同一 URL。
  • SDK 内置最多 2 路并发上传限制，超出时自动排队，无需业务层限流。

并发与线程安全

  • 所有接口均线程安全；多个 downloadSdcardFile(async=true) 可同时运行，彼此独立。
  • 进度回调在 SDK 后台线程中触发；更新 UI 控件时需切换到主线程。
  • 多个文件的回调可能并发到达，若回调内有共享状态（如进度列表），需加锁保护。

异常处理

  • 设备固件版本 < 1.1.8 时，接口抛出"不支持操作"异常，应在 UI 层隐藏该功能入口。
  • cancelSdcardFileOperation() 是唯一 noexcept 的接口；其余接口均可能抛出 ob::Error，需用 try/catch 处理。
  • 异步操作（async=true）的运行时错误通过回调中的失败状态报告，不会抛到调用线程。
